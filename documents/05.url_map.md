# System Footprint & URL Map Worksheet

## 소개

- 본격적인 코딩에 들어가기 전에, 애플리케이션의 전체 구조, 페이지 구성, 사용자 흐름 등을 한눈에 파악하는 것이 이 과제의 목표입니다.
- 단순한 기능 단위의 나열이 아니라, 사용자가 실제 어떤 흐름으로 서비스를 경험하게 되는지를 중심으로 적어보세요.
- 페이지 구성, URL 경로, 사용자 행동, 역할별 권한 등을 사전에 정리하는 작업은, 설계의 누락이나 중복을 방지하고 개발 효율을 높이는 데 도움이 됩니다.
- 실제로 개발할 때 발생할 수 있는 여러 엣지 케이스나 오류 상황도 미리 생각해봄으로써, 더 나은 사용자 경험과 안정성을 갖출 수 있을 것입니다.
- 참고 : [https://gist.github.com/serranoarevalo/9cfa38e99de1e2bcfc29194b2fdf7e3b](https://gist.github.com/serranoarevalo/9cfa38e99de1e2bcfc29194b2fdf7e3b)

## 1. 주요 흐름 (Key Flows)

*애플리케이션 내에서 사용자가 수행하게 될 3~5가지 핵심 여정을 나열해보세요. 어떤 주요 작업을 하게 될까요?*

- 회원 가입, 회원 정보 수정, 리워드 관리, 회원 탈퇴
- 목표 등록, 목표 관리,
- 만들고 싶은 습관 등록, 습관 관리,
- 실행 계획 관리
- 알림 확인
- 환경설정

## 2. 사용자가 방문할 URL/페이지

| Page Name    | URL Path    | Purpose (페이지 목적)          | Access Level (접근 권한) |
| ------------ | ----------- | ------------------------------ | ------------------------ |
| Dashboard    | / | 사용자의 현재 목표/습관 요약   | User / Admin             |
| User list    | /user       | 전체 사용자 정보 조회          | Admin                    |
| User info    | /user/:id   | 사용자 정보 조회               | User / Admin             |
| Goal list    | /goals      | 사용자의 목표 조회             | User / Admin             |
| Goal detail  | /goals/:id  | 특정 목표 조회                 | User / Admin             |
| Habit list   | /habits     | 사용자가 만들고 싶은 습관 조회 | User / Admin             |
| Habit detail | /habits/:id | 특정 습관 조회                 | User / Admin             |
| Reward       | /reward     | 사용자의 리워드 조회           | User / Admin             |
| Alarm        | /alarm      | 사용자가 받은 알림 확인        | User / Admin             |
| Alarm detail | /alarm/:id  | 사용자가 받은 상세 알림 확인   | User / Admin             |
| Settings     | /settings   | 환경 설정 보기                 | User                     |

## 3. 각 페이지에서 가능한 사용자 행동

### Dashboard (`/dashboard`)

- 오늘 해야 할 일 목록 보기
- 알림 보기
- 목표 목록 / 습관 목록 페이지로 이동
- 환경설정 보기

### User list (`/user`)

- 전체 사용자 정보 조회
- 사용자 관리
- 사용자가 작성한 글 관리

### User info (`/user/:id`)

- 사용자 정보 조회
- 사용자 정보 수정
- 회원 탈퇴

### Goal list (`/goals`)

- 사용자가 등록한 목표 목록 조회
- 새로운 목표 등록
- 목표 상세 화면으로 이동

### Goal detail (`/goals/:id`)

- 목표 상세 정보 조회
- 수정, 삭제
- 월별 / 주별 / 일별 실행 계획 확인
- 일별 수행 결과 확인

### Habit list (`/habits`)

- 사용자가 만들고 싶은 습관 목록 조회
- 새로운 습관 등록
- 습관 상세 화면으로 이동

### Habit detail (`/habits/:id`)

- 습관 상세 정보 조회
- 수정, 삭제
- 월별 / 주별 / 일별 실행 계획 확인
- 일별 수행 결과 확인

### Reward (`/reward`)

- 목표 달성으로 얻은 리워드, 달성 실패로 잃은 재화를 목록으로 조회
- 필터 및 정렬

### Alarm (`/alarm`)

- 받은 알림 목록 조회
- 알림 상세 화면으로 이동

### Alarm detail (`/alarm/:id`)

- 알림 상세 정보 조회
- 알림 삭제

### Settings (`/settings`)

- 알림 설정
- plan 변경 및 결제

## 4. 사용자 역할 및 권한

- User : 일반 사용자.
- Admin : 시스템 관리자.

## 5. 엣지 케이스 및 오류 처리

- 404 Not Found : 유효하지 않은 주소에 대한 커스텀 안내 페이지 제공
- 401 Unauthorized : 로그인 필요 안내 후 로그인 페이지로 리디렉션
- 400 Bad Request : 잘못된 요청의 경우 안내 팝업 출력 후 사용자의 대시보드 페이지로 리디렉션
- Data Validation: 잘못된 입력에 대해 명확하고 친절한 오류 메시지 제공
- Sensitive Data Handling: 민감한 세입자 정보에 대한 강화된 보호 조치
- Failed Payments: 결제 실패 시 알림 및 재시도 기능
- Mobile Limitations: 모바일 화면에 맞춘 기능 간소화 및 최적화
